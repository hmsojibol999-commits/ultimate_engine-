# Shadow-Grid

A free, phone-friendly coding and AI-helper workspace that runs in your browser.
Work in progress: see `handoff/STATUS.md` for what is done and what is not.

## Develop
```
npm install
npm run dev        # Vite dev server
npm run typecheck && npm run lint && npm test && npm run build
```

The full README (including the Bengali deployment section) is item Z-14.
